💾 Backup & Restore

📤 Export JSON

Download seluruh data (barang + peminjaman) sebagai file JSON untuk backup.

📥 Import JSON

Restore data dari file backup. Data saat ini akan ditimpa.

🔄 Reset ke Default

Kembalikan semua data ke kondisi awal (4 barang contoh, tanpa peminjaman).

ℹ️ Catatan

  • Data disimpan di localStorage browser — hilang jika cache dibersihkan.
  • Gunakan Export secara berkala untuk backup.
  • Saat Import, data lama otomatis disimpan sebagai cadangan (_backup) sebelum ditimpa.
  • Login menggunakan sessionStorage — otomatis logout saat tab ditutup.
